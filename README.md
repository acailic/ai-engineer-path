# AI Engineer Path

A free, self-contained course that takes a software engineer **with no machine-learning background to a professional level** in building with large language models: how the models work, how to build agents, how to evaluate them, how to secure them, how to ship them, and how to run them cheaply.

Everything here is synthesized from four open university sources and links back to them:

- **UC Berkeley** — LLM Agents MOOC (Fall 2024), Advanced LLM Agents MOOC (Spring 2025), Agentic AI MOOC (Fall 2025)
- **Carnegie Mellon University** — Christian Kästner, *Machine Learning in Production: From Models to Products* (MIT Press, 2025)
- **MIT 6.5940** — TinyML and Efficient Deep Learning Computing (Fall 2024)
- **Stanford CS336** — Language Modeling from Scratch (Spring 2026)

## Status

**Work in progress: chapters are being written and pushed as they are finished, so some parts are still incomplete.** The plan is 11 parts and about 100 chapters, each built on the same shape: why it matters, the core idea from first principles, a worked example, what the lecturers say (with links to the exact moments), pitfalls, an exercise, and a self-check.

| Part | Covers |
|---|---|
| 01 Foundations | How LLMs are trained and why they behave as they do, prompting, reasoning |
| 02 Building agents | The agent loop, tools, planning, memory, multi-stage systems |
| 03 Evaluation | Eval harnesses, LLM-as-a-judge, trajectory evaluation, statistics, evals in production |
| 04 Safety and security | Threat modeling, prompt injection, agent-specific attacks, defenses, red-teaming |
| 05 Frameworks and multi-agent systems | The framework landscape, AutoGen, LlamaIndex, infrastructure and protocols |
| 06 Frontier applications | Web and computer use, robotics, scientific discovery, formal mathematics |
| 07 ML in production | Requirements, architecture, deployment, operations |
| 08 Quality assurance | Slicing, behavioral testing, rubrics and judges in pipelines, production experiments |
| 09 Efficient deep learning | Pruning, quantization, distillation, TinyML, efficient LLM inference |
| 10 LLM internals | Tokenization, architectures, hardware, parallelism, scaling laws, data, post-training |
| 11 Professional practice | Capstone projects and checklists |
